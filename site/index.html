How it works

Describe your folders

Add folders in Settings and write one line about what belongs in each: "Supplier invoices, receipts, bills" beats "Finance". That text is what the classifier reads.

Drag from anywhere

Start dragging files in Finder or any app. The shelf slides in from the edge you chose. Every matching tile lights up with a count while you are still dragging.

Drop once

Drop anywhere on the shelf. Each tile shows a progress bar as its files move, then "Moved n". Files that match nothing stay where they were.

Details that matter

Two engines

TypeSafe Jev, a cloud decision model that answers in about a hundred milliseconds, or Apple's on-device model, fully offline, one to three seconds. Switch in Settings.

Bring your own server

The Jev URL is configurable. Point it at api.typesafe.ai, an open alternative, or a compatible server on localhost. The API key is optional for anything but hosted TypeSafe.

Metadata only

By default only file name, extension and size leave your Mac. Kind, dates, parent folder and a 512-byte text snippet are opt-in, each labelled with what it reveals.

See the exact payload

Advanced settings show the request as it will be sent, with your folders and either sample files or your last drag. Edit the template, copy it, or keep a memory-only log of the last ten requests.

Nothing stored but your folders

Folder paths and descriptions live in one JSON file. The API key lives in your login Keychain. No accounts, no telemetry, no update pings, no history of what you moved.

Stays out of the way

Menubar only, no Dock icon unless you want one. Shelf from top, right, bottom or left. Name collisions become name (2).ext, never overwrites. Folders in a drag are ignored.

Install

This is a free app without a paid Apple developer account behind it, so the download is not notarized and macOS blocks the first launch. Two ways past that, pick one.

Terminal, one line

curl downloads carry no quarantine flag, so Gatekeeper never fires.

curl -fsSL https://github.com/diwakersurya/mac-dnd-categoriser/releases/latest/download/DnDCategoriser.zip -o /tmp/DnDCategoriser.zip && rm -rf /Applications/DnDCategoriser.app && ditto -x -k /tmp/DnDCategoriser.zip /Applications && open /Applications/DnDCategoriser.app

Finder

  1. Download, unzip, drag DnDCategoriser.app to Applications and open it. macOS says it could not verify the app. Click Done.
  2. System Settings → Privacy & Security → scroll down → "DnDCategoriser was blocked" → Open Anyway, then authenticate.
  3. Open the app again and confirm.

Shortcut for the same thing: xattr -dr com.apple.quarantine /Applications/DnDCategoriser.app

First launch. The app lives in the menubar and opens Settings because no folders exist yet. macOS asks once per folder before the app may move files into Desktop, Documents or Downloads. Prefer building from source? git clone, then make cert && make install. The README has the details.

Privacy

With the on-device engine nothing leaves your Mac. With Jev, the request you can inspect under Advanced is sent to the server you configured when a drag starts, nothing else, nowhere else. There is one network destination in the whole codebase and you choose it. The full data inventory, network table and security model are in ARCHITECTURE.md.
